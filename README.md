# MOTH EMPIRE — Made Out The Hood

This project is positioned around the Dior Going Digital aesthetic: luxury, digital access, statement culture, and collectible scarcity.

It includes:

- a mobile-first landing page
- a free game experience
- a live trading demo toy
- a merch waitlist flow
- a shop / drop touchpoint

## Local preview

```bash
cd /Users/mothworldwide/Downloads/moth-character-creator/madeoutthehood/Untitled
python3 -m http.server 8000
```

Then open:

- http://localhost:8000/index.html
- http://localhost:8000/game.html
- http://localhost:8000/index-3.html
- http://localhost:8000/shop.html

## Domain and deploy

Point madeoutthehood.org at the Vercel project that contains this static app.

## Dior Going Digital angle

Use the site to frame the brand as a digital luxury ecosystem rather than just a generic clothing store:

- game for attention
- live trading demo for intrigue
- merch waitlist for conversion
- premium visual tone for status and desire

This keeps the pitch aligned with luxury digital culture while still feeling practical and launch-ready.
